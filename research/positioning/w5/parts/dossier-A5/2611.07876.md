# Which signals of code correctness survive shift (2611.07876)
Status: concurrent preprint. Text basis: FULL TEXT, arXiv v1 (2026-11-05; still the only version per export.arxiv.org on 2026-11-10), raw/2611.07876v1.pdf.

Measured: six execution-free predictors in four families (Yes/No token confidence, EigenScore, logistic probe and LAT, DAS counterfactual simulation and value probe) for two targets, program correctness and verdict correctness, in distribution and under benchmark and language shift (Sections III-IV).
Models and benchmarks: Qwen3-Coder-30B-A3B-Instruct, gpt-oss-20b (V-A a); LiveCodeBench release_v6 and BigCodeBench; 454 LCB problems released Oct 2024-May 2025 in Python, C++, Java; n=10 at t=1; 60/20/20 split by problem, three partitions (V-A b-d).
Findings: verdict target, Qwen3-Coder language shift: Probe ID .761, Shift .668; Confidence .644, .643 (Table II). gpt-oss LCB verdict: Probe .829 vs Confidence .569 (Table II). Program target within problem under language shift: "0.58-0.64 for all methods and both models"; Qwen3-Coder confidence best at 0.629 (VI-C c). A probe at the last prompt token, input only, gives .891 pooled vs .886 judging pass, Qwen3-Coder ID (Table V). Reasoning raises gpt-oss Yes-probability AUROC "from 0.68 to 0.73" (VIII a).
Leaves open: verbal numeric confidence, trained stated confidence, base/instruct, calibration metrics, routing experiments.

Breadth:
- confidence families: token probability, sampling (EigenScore), probe/LAT, causal; verbal absent
- model families: 2; scales 20B, 30B MoE (3B active)
- benchmarks: LCB, BCB; Python, C++, Java
- base/instruct, post-training stages: not present
- reasoning: gpt-oss final channel prefilled, no reasoning (V-A a); one reasoning check on 498 candidates (VIII a)
- label source: execution on benchmark tests
- contamination: release window defines the language sets only; no contamination analysis
- calibration metrics: AUROC only (searched: ECE, Brier)
- inference: paired problem-clustered bootstrap, 2,000 resamples (V-C b)
- granularity: candidate, within problem, problem

Bears on: L2 (probe vs readout, within problem): NARROWS. L1: no effect.
