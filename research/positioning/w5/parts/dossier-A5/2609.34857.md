# CREDO: calibrating reasoners with differentiable readouts (2609.34857)
Status: preprint (Fan et al.). Text basis: FULL TEXT, arXiv v1 (2026-09-28, only version), raw/2609.34857v1.pdf. Same paper as the vault CREDO note.

Measured: stated confidence trained inside RLVR on execution-graded correctness. CREDO reads c = sigma(z_H - z_L) from two reserved tokens (Section 3.1, Eq. 6), regressed toward t = gamma a + (1 - gamma) group mean (3.2, Eq. 7). RLCR and DCPO train a sampled verbal numeral via reward (2.2, Eq. 4); GRPO has no calibration term. "-d" rows read baselines by digit expectation (B.3, Eq. 19).
Models and benchmarks: Qwen3-8B only for code (B.1); math also at 1.7B and 4B (C.1). Code trains on DeepCoder (9,500), evaluates on DeepCoder test (500), HumanEval+ (163), LCB v5 (279), LCB v6 (131), n=4 per problem (Table 5).
Findings: code in domain, macro over four sets: AUROC CREDO .850, RLCR .815, DCPO .776, GRPO .753, Base .690; ECE .064 vs RLCR .075 (Table 1). DCPO-d AUROC .849 nearly matches CREDO (Table 1); on LCB v6, CREDO .887 vs DCPO-d .896 (Table 13). Code AURC 16.80 vs DCPO 21.26 (Table 3).
Leaves open: probes (searched: probe, hidden state: 0 hits), input-only baselines, within-problem metrics, contamination.
