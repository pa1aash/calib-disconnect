# Fine-grained calibration for automated code revision (2604.06723)
Status: preprint only (arXiv v1 posted 2026-04-08). Source: research/notes/fine-grained-approaches-for-confidence-calibration-of-llms-in-automated-code-rev.md. Text basis: FULL TEXT.

Measured: calibration of sequence-level vs fine-grained token confidence scores (minimum token probability, lowest-K, attention-weighted) with global and local Platt scaling. Models and benchmarks: 14 models (Llama-3.1 8B/70B, CodeLlama 7B/70B, Qwen2.5 7B/72B, Qwen2.5-Coder 7B/32B, others); DCF-Bug (777), DCF-Vul (1,041), CR-Trans (900) (Table I); zero-shot, greedy decoding. Findings: "minimum token probability is the best-performing confidence score across all tasks, correctness metrics, and models considered" (Introduction); local Platt scaling beats global (Tables II onward); sequence-level scores suffer single-bin collapse. Leaves open: correctness is not execution: exact match, edit progress, or static-analysis checks passed (Section IV-F; searched: execution, unit test, pass@1, no hit); no verbal or probe readout.

Breadth:
- confidence families: token probability variants only (P(True) and sampling excluded by design).
- model families: Llama, CodeLlama, Qwen2.5, Qwen2.5-Coder, others.
- scales: 7B to 72B.
- benchmarks: three revision tasks, not generation.
- base and instruct pairs: not present (searched: base model).
- post-training stages: not present.
- reasoning vs non-reasoning: not present (searched: reasoning).
- elicitation formats: not present (searched: verbaliz).
- label source: exact match, edit progress, static-analysis checks; no tests.
- label independence: not present.
- contamination split: partial; non-permissive-license test sets and semantic-preserving rewrites (Section VIII).
- calibration metrics: ECE (10 equal-width bins), Brier, and Bin Coverage (BC).
- granularity: token and edit level scores, scored against whole-revision labels.
- causal intervention: not present.

Bears on: L4 (line, token, edit-level confidence, question 4): NARROWS; per-edit recalibration exists with text-match labels, no localization evaluation or per-test-group confidence. L1 (calibration estimators): no effect.
