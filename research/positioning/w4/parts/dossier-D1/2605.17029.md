# CodeRefuser, task abstention for code generation (2605.17029)
Status: concurrent (arXiv submitted 2026-05-16). Source: research/notes/260517029-task-abstention-for-large-language-models-in-code-generation-full-text.md. Text basis: FULL TEXT.

Measured: risk-controlled abstention (Learn-Then-Test over a threshold vector) using execution-cluster ratio or semantic entropy over model-generated tests, with sample-test dual filtering (STDF). Models and benchmarks: DeepSeek-Coder-33B, Qwen2.5-Coder-32B, CodeLlama-7B, WizardCoder-33B-V1.1; HumanEval and MBPP, Python only; temperature 0.8, top-p 0.95, 60/40 calibration and test split, alpha=0.2, delta=0.1, k=3 (Section 4). Findings: "CODEREFUSER achieves an average of 26.5% and 11.9% absolute improvements w.r.t. abstention precision and F1-score" over the best existing result (Section 4, Table 1); abstention label is H@k (all k samples wrong) against the risk tolerance, computed with oracle tests (Section 3). Leaves open: abstention decision only, not allocation of execution or sampling budget against random and oracle routing (L3); no verbal confidence, no probe.
