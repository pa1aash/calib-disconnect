# Probing functional correctness in diffusion language models (10.18653/v1/2026.acl-srw.15)
Status: published or accepted (ACL Student Research Workshop 2026, Anthology ID 2026.acl-srw.15, revision 2 dated 2026-10-21). Source: research/notes/probing-functional-correctness-in-diffusion-language-models-full-text.md. Text basis: FULL TEXT.

Measured: logistic-regression probes on hidden states across denoising steps and layers, predicting functional correctness; offline probe-gated skipping. Models and benchmarks: LLaDA-8B and Dream-7B; JSON schema (272), GSM8K (1,319), MBPP (257 sanitized, assertion-verified), ARC-Challenge; 5-fold CV, AUC (Section 4). Findings: MBPP baseline pass rates LLaDA 40.9%, Dream 44.4% (Table 1); "DLMs gain a further 0.08-0.11 AUC" on reasoning tasks; step-0 signal comparable to an AR probe on the same prompt, so attributed to prompt difficulty; filtering simulation compute saved 36.0% to 98.4% (Table 2); probe beats raw entropy, max-probability, and LR-entropy baselines (Section 5, Appendix). Leaves open: diffusion models only, one code task, no verbal readout.

Breadth:
- confidence families: probe vs token entropy and max-probability; no verbal, no sampling agreement.
- model families: two diffusion models (plus one AR control, Qwen2.5-7B-Instruct).
- scales: 7B to 8B.
- benchmarks: four, one code (MBPP).
- base and instruct pairs: not present (AR base only as a control; searched: base model).
- post-training stages: not present.
- reasoning vs non-reasoning: task type varied (structural vs reasoning), not model type.
- elicitation formats: not present (searched: verbal).
- label source: execution of MBPP assertions; exact match for others.
- label independence: not present; probe labels from the same generation.
- contamination split: not present (searched: contaminat, cutoff).
- calibration metrics: AUC, classification accuracy; no ECE (searched: ECE, Brier).
- granularity: whole output, per denoising step.
- causal intervention: not present; steering only in related work.

Bears on: L2 (probe on code correctness, non-AR): NARROWS, different architecture, no verbal comparison. L3 (probe-gated compute): no effect for execution-budget routing. L1, L4: no effect.
