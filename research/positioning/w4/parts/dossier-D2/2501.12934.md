# Openia internal-representation probe for code (2501.12934)
Status: published (Journal of Systems and Software 2025, DOI 10.1016/j.jss.2025.112570 per the vault note; journal version not reached); first posted January 2025. Source: research/notes/correctness-assessment-of-code-generated-by-large-language-models-using-internal.md. Text basis: FULL TEXT (arXiv HTML).
Measured: a probe on the last generated token's last-layer hidden state predicting code correctness, versus LLM-Check, CodeBERT and CodeT5+ classifiers, and zero-shot LLM-as-judge (Baselines; RQ1 to RQ4).
Models and benchmarks: instruction-tuned DeepSeek-Coder 1.3B and 6.7B, Code Llama 7B and 13B, Magicoder-7B; HumanEval (164), MBPP (500), DevEval (1,825); 10 samples per task (Dataset Construction; Table 1).
Findings: "up to a 2X improvement in standalone code generation and a 3X enhancement in repository-specific scenarios" (Abstract). A prompt-template shift between MBPP and HumanEval gives F1 0.67 (Prompt Variability).
Leaves open: the judge is a zero-shot correctness query, with no numeric confidence or token-probability readout (searched: verbalized, confidence score, ECE). Bears on L2 questions 1, 2, 5, and 6.
Breadth:
- confidence families: probe, LLM-as-judge, LLM-Check, embedding classifiers
- model families: 3
- scales: 1.3B to 13B
- benchmarks: 3, plus a cross-language test (Java, JavaScript, Python, TypeScript)
- base and instruct pairs: not present (instruction-tuned only)
- post-training stages: not present
- reasoning vs non-reasoning: not present (searched: reasoning model)
- elicitation formats: one zero-shot judge prompt
- label source: benchmark tests, all must pass
- label independence: not present (searched: independent)
- contamination split: not present (searched: contamin, release date)
- calibration metrics: weighted accuracy, precision, recall, F1; no ECE or AUROC
- granularity: whole solution; token and layer analysis (RQ2)
- causal intervention: not present
Bears on: L2 "probe predicts execution-graded correctness, with transfer": NARROWS (probe beats judge on three model families; numeric verbal confidence, sampling, base and instruct pairs, reasoning absent). Others: no effect.
