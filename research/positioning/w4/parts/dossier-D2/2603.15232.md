# Decomposing probabilistic scores (2603.15232)
Status: preprint only (first posting March 2026; v2 dated 22 Mar 2026; no venue found in text). Source: research/notes/decomposing-probabilistic-scores-reliability-information-loss-and-uncertaintysup.md. Text basis: FULL TEXT (supplementary-material version).
Measured: theory. Decomposition identities for arbitrary proper losses: expected loss at an information level splits into proper regret (reliability) plus conditional entropy; for a score S=s(X), a three-term identity of miscalibration, grouping (information loss from X to S), and irreducible uncertainty (Abstract; Theorems 2.1 to 2.6; Proposition 3.2).
Models and benchmarks: none for language models; synthetic data and a GermanCredit case study (Experiments).
Findings: "post-hoc recalibration can only reduce (i); to reduce (ii) one must change the score/representation" (Introduction, contributions). Perfect calibration is compatible with severe information loss (Proposition 3.2 discussion).
Leaves open: no LLM, code, or readout content (searched: language model, LLM, code generation, hidden state). It supplies the vocabulary that a calibration-relative-to-information-level split already exists, so any F quantity must differ from the grouping term.
