# Which signals of code correctness survive shift (2611.07876)
Status: concurrent (arXiv v1 2026-11-05, preprint only). Source: research/notes/which-signals-of-code-correctness-survive-distribution-shift-hidden-state-and-ca.md. Text basis: FULL TEXT.
Measured: six execution-free predictors in four families (Yes-token confidence, EigenScore, linear probe and LAT, DAS-based causal predictors) for program correctness and for the model's own verdict correctness, under benchmark and language shift (Sections III-VI).
Models and benchmarks: Qwen3-Coder-30B, gpt-oss-20b; LiveCodeBench release_v6 (454 problems released Oct 2024-May 2025 for language sets) and BigCodeBench; n=10 samples at t=1; 60/20/20 split by problem (Section V).
Findings: Qwen3-Coder language shift: Probe ID .761, Shift .668; Confidence ID .644, Shift .643 (Table II). gpt-oss probe LCB-trained .829 vs Confidence .569. Medium-effort reasoning raises gpt-oss AUROC of Yes probability "from 0.68 to 0.73" (Section VIII).
Leaves open: no verbal numeric confidence, no base/instruct, no calibration metric, reasoning off by design, no budget routing.
Breadth:
- confidence families: token probability, sampling (EigenScore), probe, causal; verbal numeric absent (searched: verbalized)
- model families: 2
- scales: 20B and 30B
- benchmarks: LCB, BCB; Python, C++, Java
- base/instruct pairs: not present (searched: base model)
- post-training stages: not present
- reasoning vs non-reasoning: gpt-oss judged without reasoning; one reasoning-on check (Section VIII)
- elicitation formats: one judging prompt, Yes/No token
- label source: execution on benchmark tests
- label independence: verdict labels use the judged candidate's own tests
- contamination split: problem-level partitions; release-window use for languages only, not a calibration split
- calibration metrics: AUROC; ECE not present (searched: ECE, Brier)
- granularity: candidate and problem
- causal intervention: DAS interchange for prediction, not changing stated confidence
Bears on: L2 (probe vs readout, causal): NARROWS. L1: no effect.
