# Hard Issue, Weak Model, or Bad Run? (2611.08285)
Status: concurrent (arXiv v1 2026-11-05, preprint only). Source: research/notes/hard-issue-weak-model-or-bad-runrethinking-failure-prediction-for-coding-agents.md. Text basis: FULL TEXT (the note ends after Section III preliminary findings).
Measured: whether trajectory-based failure predictors learn about the run beyond issue difficulty and model ability; the oracle gap and per-issue model switching; retry in a repeated-run pilot (Sections II-III).
Models and benchmarks: mini-swe-agent trajectories on 500 SWE-bench Verified issues, 3,492 runs from seven models (Claude Haiku 4.5, Claude Opus 4.5 and 4.6, Gemini 3 Flash, GLM-5, GPT-5-mini, MiniMax-M2.5), 23-model outcome data, and a Llama 70B and 8B repeated-run corpus (Section II). Predictors: TF-IDF logistic regression, Qwen3-0.6B LoRA.
Findings: Table I: Issue difficulty pooled AUROC 0.924; TF-IDF full prefix (ALL) 0.630. Equivalence-test gain beyond difficulty and ability "equivalent to zero in all 18 configurations". Router "gains only +0.41 pp over the best single model" (Section III-B).
Leaves open: agent trajectory predictors, not a model's stated confidence. Warns that pooled AUROC mostly measures cross-issue difficulty, which bears on L1 reporting (L2 question 13). No budget routing by confidence.
