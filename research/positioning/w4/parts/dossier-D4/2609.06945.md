# Brier-UDAM paired Brier-risk decomposition (2609.06945)
Status: preprint only (arXiv 2609; first posting date not verified from the note). Source: research/notes/brier-udam-for-paired-prediction-rule-comparisons-full-text.md. Text basis: FULL TEXT.
Measured: exact decomposition of the paired Brier-risk difference into mean-bias, dispersion, and alignment terms, with influence-function inference (Abstract; Eq. 5: R(p) = U + M(p) + D(p) + L(p), L = -2A; Proposition 1).
Models and benchmarks: no LLM content. Simulations (Table 1, Table 2) and a public-data 30-day hospital readmission analysis with GLM, LASSO, and random forest (Sec 4.5).
Findings: "The Brier score was 0.07991 (95% CI, 0.07700-0.08282) for GLM, 0.07984 (0.07692-0.08275) for LASSO, and 0.08009 (0.07722-0.08295) for random forest" (Sec 4.5.1); similar Brier risks hid larger, opposing dispersion and alignment contributions (Sec 4.5.2, Table 4).
Leaves open: for F, it is a covariance-style Brier decomposition of the kind the brief names (A24); it has no internal reference, readout, or format dimension.
