# AutoProbe (2510.02934)
Status: preprint only (arXiv id 2510, Oct 2025; journal record not verified in this dossier). Source: research/notes/model-agnostic-correctness-assessment-for-llm-generated-code-via-dynamic-interna.md (16k words). Text basis: FULL TEXT.
Measured: attention-weighted hidden-state probe (learned layer and token-position importance) predicting compilability, functionality, and security labels; accuracy, precision, recall, F1 (Sections 3, 4.4, 5.1).
Models and benchmarks: DeepSeek-Coder 1.3B/6.7B, Code Llama 7B/13B, Magicoder-7B, CodeGemma-7B, all at most 13B (Section 4.2); HumanEval, MBPP, DevEval, SecurityEval, CWEval, CodeGuard+, SALLM (Section 4.1); train MBPP, test HumanEval.
Findings: security accuracy up to 18% above Openia (Table 4); In-house LLM-AJ (self-judge) 0.32 to 0.61 accuracy on functionality (independent-unit, Table 5, first three models) versus External LLM-AJ (o4-mini) 0.93 to 0.97; probe 0.63 to 0.71.
Leaves open: no probabilities or calibration metrics; verbal confidence is a binary zero-shot judge, not a numeric score; whole solution only.
