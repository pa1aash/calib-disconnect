# Multicalibration for LLM-based Code Generation (2512.08810)
Status: preprint only (arXiv id 2512, Dec 2025; the PDF header reads "arXiv preprint; 2025"). Source: research/notes/multicalibration-for-llm-based-code-generation.md (7.8k words, arXiv HTML). Text basis: FULL TEXT.
Measured: post-hoc calibration (Platt, histogram binning, group-conditional regression, iterative grouped binning) of token-likelihood confidence against unit-test correctness, with groups such as complexity, code length, language (Sections 4-6).
Models and benchmarks: Qwen3-Coder-30B-A3B-Instruct, GPT-OSS-20B, DeepSeek-R1-Distill-Qwen-32B (Section 5.2); LiveCodeBench v6 (1,055 problems), MultiPL-E, McEval (Section 5.1).
Findings: "After calibration, accuracy rose to between 72.5% and 95.5%" (Section 6.1); uncalibrated Qwen3 on LiveCodeBench ECE 0.294 for avg_prob (Table 2). IGLB and LINR/LOGR best (Table 1).
