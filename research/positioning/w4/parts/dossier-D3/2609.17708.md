# Confidence Comes from Experience, XConf (2609.17708)
Status: concurrent (arXiv v1 15 Sep 2026, preprint only). Source: research/notes/confidence-comes-from-experience-experiential-confidence-estimation-from-reasoni.md (22.9k words). Text basis: FULL TEXT.
Measured: XConf, a black-box estimator that retrieves the model's own graded past episodes with similar stated confidence and restates confidence from that track record; AUROC, ECE, AURC, Brier, selective prediction.
Models and benchmarks: Gemini 2.5 Flash, Gemini 3.5 Flash, Claude Sonnet 4.6, Qwen3.5-397B; nine benchmarks, one code set (LiveCodeBench, 1,055 problems, unit tests) plus SWE-bench Verified (Table 2).
Findings: on LiveCodeBench, SC@10 (pairwise code similarity) reaches ".742 to .804" AUROC, below XConf by ".06 to .13" on every column (Section 5.2); verbalized AUROC .587 to .789 (per-dataset table, Section 5.2). Abstaining on the lowest 10% adds 5.4 points on LiveCodeBench with Claude (Figure 5).
Leaves open: updates use outcomes of other episodes, not the same program's observed test failures; no probes; code is one of nine sets.
