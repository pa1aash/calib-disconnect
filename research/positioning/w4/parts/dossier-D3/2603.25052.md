# Closing the Confidence-Faithfulness Gap (2603.25052)
Status: preprint only (arXiv id 2603, v2 1 Apr 2026). Source: research/notes/closing-the-confidence-faithfulness-gap-in-large-language-models.md (8k words). Text basis: FULL TEXT.
Measured: ridge probes for accuracy and for verbalized confidence, contrastive activation addition (CAA) steering of verbalized confidence, and a two-stage adaptive steering pipeline (Sections 2.1, 2.2, 3.8).
Models and benchmarks: Llama-3.1-8B, Qwen2.5-7B, Mistral-7B-v0.1, each base and instruct (Methods); MATH, MMLU, TriviaQA, TruthfulQA; no code.
Findings: accuracy probe Cohen's d = 1.88, r = 0.80 (Figure 1); accuracy and verbal-confidence directions have "cosine similarity < 0.04" (Section 3.3); joint solve-and-rate prompting moves it from +0.26 to -0.63 (Section 3.4); base-derived vectors shift instruct confidence (Table 3); steered ECE on MATH, Llama: 14.9 to 3.7 (Table 4).
Leaves open: code and execution labels; models are all 7-8B; "reasoning" is a joint prompt, not reasoning models.
