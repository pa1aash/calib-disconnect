# ACES: leave-one-out AUC test weighting (2604.03922)
Status: preprint only (arXiv id 2604, v2 dated 2026-07-12; v1 date not verified). Source: research/notes/aces-who-tests-the-tests-leave-one-outauc-consistency-for-code-generation.md. Text basis: FULL TEXT.
Measured: weighting LLM-generated tests by leave-one-out AUC from the binary code-by-test pass matrix to select candidates; Pass@k (Sec. 2, 4).
Models and benchmarks: GPT-3.5-Turbo candidates (about 200) and tests (about 500) per problem from Huang et al. (2024); HumanEval, HumanEval+, MBPP (Sec. 4.1). Appendix C adds other models.
Findings: Table 2, HumanEval Pass@1: GPT-3.5-Turbo 68.38, Majority Voting 80.49, ACES-C 82.93, ACES-O 84.15. Abstract: expected LOO-AUC is "proportional to each test's ability to separate correct from incorrect code".
Leaves open: Self-written test adequacy is addressed as ranking, not as a confidence or calibration quantity (searched: confidence, calibrat; only boilerplate matches). No per-requirement grouping, no localization, no repair.
Breadth:

- Model families: GPT-3.5-Turbo for the pool.
