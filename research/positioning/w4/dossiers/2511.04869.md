# Semantic calibration emerges from pretraining (2511.04869)
Status: preprint only (arXiv v1 posted 2025-11-06; text dated 2026-08-24; no venue stated). Source: research/notes/trained-on-tokens-calibrated-on-conceptsthe-emergence-of-semantic-calibration-in.md. Text basis: FULL TEXT.

Measured: sampling-based semantic calibration (confidence is the share of 50 samples in a meaning class), with a B-calibration theory predicting when it holds. Models and benchmarks: Qwen, Gemini, Mistral, and Llama families, 0.5B to 72B, base and instruct variants; GSM8K, OpenMathInstruct-2, TriviaQA, SimpleQA; 5-shot, temperature 1, three response styles (concise, sentence, CoT); over 650 experiments (Section 5, Fig. 2). Findings: "(1) Base LLMs are semantically calibrated across question-answering tasks, (2) RL instruction-tuning systematically breaks this calibration, and (3) chain-of-thought reasoning breaks calibration" (Abstract); calibration measured with SmoothECE, fixed bandwidth 0.05 (Appendix D.1). Leaves open: no code, no execution labels, no probe or verbal readout; the base-vs-instruct contrast for code with several readouts is not tested.

Breadth:
- confidence families: sampling-based semantic confidence only.
- model families: four.
- scales: 0.5B to 72B.
- benchmarks: four (math and factual QA), no code.
- base and instruct pairs: yes, many (Section 5.1, Fig. 2).
- post-training stages: base vs instruct; RL and DPO instruction tuning discussed (Prediction 2).
- reasoning vs non-reasoning: CoT vs direct answer, not reasoning models.
- elicitation formats: three response styles for sampling, not confidence elicitation formats (searched: verbaliz).
- label source: matched final answers or LLM-extracted answer classes (Qwen3-14B-Instruct clustering).
- label independence: not present.
- contamination split: not present (searched: contaminat).
- calibration metrics: SmoothECE.
- granularity: question level.
- causal intervention: not present (searched: steer, ablat).

Bears on: L2 (base vs instruct, location of the gap): NARROWS; general-domain sampling-calibration precedent that RL tuning and CoT break calibration, so a code claim needs execution labels and probe, verbal, and sampling readouts together. L1: no effect.
