# Code Is More Than Text: three-axis code UE (2606.09577)
Status: concurrent (arXiv v1 2026-06-08, preprint only). Source: research/notes/code-is-more-than-text-uncertainty-estimation-for-code-generation.md. Text basis: FULL TEXT.
Measured: post-hoc uncertainty for code: Top-K token entropy, pseudo-code consistency, self-generated-test behavioral consistency, and a rank-normalized ensemble (Sections 2.2-2.5).
Models and benchmarks: Qwen3-14B, Qwen3-32B, Qwen3-Coder-30B-A3B-Instruct, Devstral-Small-2505, DeepSeek-Coder-V2-Lite-Instruct; APPS-Intro (N=1000), APPS-Interview (N=1000), HumanEval (164), MBPP (500) (Section 4).
Findings: AUROC from 0.696 (strongest NL baseline) to 0.776 (abstract). Code-only entropy AUROC 0.716, comment-only 0.375 (Section 5).
