# Ensemble semantic entropy for code (2603.27098)
Status: preprint only (arXiv ID 2603, v2 dated 2026-04-04; first posting before 2026-05-10). Source: research/notes/ensemble-based-uncertainty-estimation-for-code-correctness-estimation.md. Text basis: FULL TEXT.

Measured: Ensemble Semantic Entropy (ESE), execution-output clustering of samples pooled from two models, against single-model entropy scores, plus an uncertainty-gated cascade (Cas). Models and benchmarks: GLM4-9B, Qwen3-8B/14B, Qwen3-Coder-30B-A3B/485B-A35B, gpt-oss-20B/120B; LiveCodeBench release v2; M=12 samples per problem; clustering tests generated by Qwen3-Coder-30B (Section 5.1). Findings: "in selective generation tasks with strict false-positive rate constraints, ESE improves prediction accuracy by 53.4%"; Cas "reducing FLOPs by 64.9% compared to single-model scaling" (Abstract; Section 6); correlation with correctness is Pearson, EDSE up to -0.7400 (Table 1). Leaves open: sampling family only; L3 routing here is model-size cascade, with no random or oracle routing baseline (searched: oracle, random); no probe or verbal readout.

Breadth:

- model families: three (GLM, Qwen3, gpt-oss).
- scales: 8B to 485B.

- base and instruct pairs: not present (searched: base model).

- elicitation formats: not present (no verbal readout).

- calibration metrics: Pearson correlation, selective accuracy at FPR; no AUROC or ECE.
