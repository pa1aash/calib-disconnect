# Don't Ask: numeric self-reports (2603.18893)
Status: preprint only (arXiv ID 2603; v3 dated 2026-10-10; first posting before 2026-05-10). Source: research/notes/dont-ask-understanding-what-numeric-self-reports-measure-in-language-models.md. Text basis: FULL TEXT.

Measured: coupling between a numeric self-rating and linear probe scores for four affective concepts (wellbeing, interest, focus, impulsivity) over ten-turn conversations. Models and benchmarks: eight instruct models, LLaMA 3.2 1B/3B, LLaMA 3.1 8B, Gemma 3 1B/4B/12B/27B, Qwen 2.5 7B; simulated conversations, no benchmark. Findings: "the probe explains on average only 2.0% of the variance of the rating" before the question (Section 3.1); the rating tracks the probe after the question (Section 3.2); steering is non-specific (Sections 3.2 to 3.3); no improvement from 1B to 27B (Section 3.4). Leaves open: not about correctness, confidence, or code. Supports F only as a reactivity argument (asking a number perturbs the state read).

Breadth:
- confidence families: numeric self-report vs probe (affect, not confidence).
- model families: three (LLaMA, Gemma, Qwen).
- scales: 1B to 27B.
- benchmarks: not present (searched: HumanEval, execution, accuracy).
- base and instruct pairs: not present (all instruct).
- post-training stages: not present.
- reasoning vs non-reasoning: not present (searched: reasoning model, thinking).
- elicitation formats: one 0-9 rating, read from the digit-token distribution; subject variant (user) tested.
- label source: probe scores; no correctness label.
- label independence: not applicable.
- contamination split: not present.
- calibration metrics: none; mixed-model associations.
- granularity: assistant turn.
- causal intervention: present, steering along affective directions (Sections 3.2 to 3.3).

Bears on: F (1, 3): NARROWS slightly; measurement-validity vocabulary exists for self-reports, but not for confidence on code. L1 to L4: no effect.
