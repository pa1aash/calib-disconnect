# CoTT: confidence-gated test generation (2609.12489)
Status: concurrent (posted 2026-09-11). Source: research/notes/confidence-gated-transductive-test-generation-for-code-reranking.md. Text basis: FULL TEXT.
Measured: reranking of five candidate programs per task by pass rate on synthesized tests whose expected outputs come from inductive generation, with transductive generation invoked only when inductive output agreement is low (Sec. 3, 4).
Models and benchmarks: Llama-3.1-8B-Instruct (single LLM); HumanEval-R+ and MBPP-R+.
Findings: Table 1 average cost per problem: "TT w/o Gating" $0.077, "CoTT" $0.065; CoTT is best on some reranking metrics (Top-1, Bottom-1, Spearman) per benchmark. Limitations: "single efficient LLM on two function-level Python code-reranking benchmarks".
Leaves open: The gate is agreement among sampled outputs on a test input, not model confidence in a solution. No routing of execution budgets across solutions, no random or oracle routing arm, no verbal confidence updated after failed tests (searched: verbalized, logprob, oracle, random).
