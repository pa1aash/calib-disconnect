# PtTrust (2504.14640)
Status: published (FSE Companion '25, 23-28 June 2025, DOI 10.1145/3696630.3728566; arXiv v1 20 Apr 2025). Source: research/notes/risk-assessment-framework-for-code-llms-via-leveraging-internal-states.md (12.5k words). Text basis: FULL TEXT.
Measured: line-level and snippet-level error risk from internal states: unsupervised sparse-autoencoder pre-training, then a small labeled risk predictor; Top-K hit rate for error lines and snippet classification (Sections 4.2, 4.3).
Models and benchmarks: Code Llama-34B, Qwen2.5-Coder-32B, StarCoder2-15B (Section 4.1.2); evaluation on EditEval, Code Lingua (Python-Java AVATAR), Defects4J; semantic-binding stage on HumanEval, EvalPack, QuixBug (368 instances) (Section 4.1.1).
Findings: Code Llama Top-1 on Code Lingua 0.223 versus 0.040 for token-uncertainty (Table 2); Defects4J Top-3 0.479 versus 0.499 for uncertainty (Table 2, PtTrust does not win); snippet classification wins are mixed, e.g. Defects4J Code Llama 0.515 (Table 5).
Leaves open: no verbal or sampling readout; no calibration metrics; line labels come from GPT-4o corrections checked by tests and manual review (Section 6), not per-test groups; no repair-versus-regeneration test.
