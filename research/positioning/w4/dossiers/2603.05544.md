# Yates covariance decomposition rearrangement (2603.05544)
Status: preprint only (arXiv id 2603, v2 22 Jun 2026). Source: research/notes/260305544-yates-covariance-decomposition-rearrangement-for-brier-score-full-text.md. Text basis: FULL TEXT (short theory note).
Measured: nothing empirical. Algebraic rearrangement of the Yates decomposition of the Brier score (Section 2, Theorem 1).
Models and benchmarks: none. No LLM or code content (searched: language model, LLM, code, confidence).
Findings: BS = (sigma_F - sigma_Y)^2 + 2(sigma_F sigma_Y - sigma_FY) + (mu_F - mu_Y)^2, three non-negative terms: variance mismatch, covariance deficit, calibration-in-the-large (Theorem 1, Corollary 1). Optimality needs variance matching, perfect correlation, and no bias (Corollary 2).
Leaves open: it is the closest standard bias/variance-style decomposition for F, but it compares forecast to outcome, never to an internal reference. A readout-versus-internal-state bias, resolution, and noise split is not in it.
