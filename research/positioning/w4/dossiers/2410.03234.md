# HonestCoder, showing code selectively by confidence (2410.03234)
Status: preprint only (arXiv v1 posted 2024-10-04; no venue found in the text). Source: research/notes/showing-llm-generated-code-selectively-based-on-confidence-of-llms.md. Text basis: FULL TEXT.

Measured: confidence from multi-modal similarity among sampled programs, scored by AUROC and AUCPR for separating passed from failed requirements, then used to decide whether to show code. Models and benchmarks: DeepSeek-Coder-Instruct 1.3B and 6.7B, Code Llama-Instruct 7B and 13B; TruthCodeBench, 2,265 Python and Java requirements with LLM-specific pass or fail labels; N=20 samples. Findings: HonestCoder outperforms the best baseline "by 27.79% in AUROC and 63.74% in AUCPR" (Abstract); Table 2 (Python), CodeLlama-13B-Ins AUROC: 74.05% vs Average Prob. 56.64%. Leaves open: eight baselines include Self-Asking (Re.), the token probability of "Yes" to a can-you-solve prompt, but no numeric verbal confidence and no probe (the text lists hidden-state estimation as future work). Label: passed if at least one of K programs passes all tests.
