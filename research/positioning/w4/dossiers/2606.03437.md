# LLMs are overconfident in their own responses (2606.03437)
Status: concurrent (arXiv v1 2026-06-02, preprint only). Source: research/notes/large-language-models-are-overconfident-in-their-own-responses.md. Text basis: FULL TEXT.
Measured: calibration of base, instruction-tuned without chat template, and instruction-tuned with chat template; "ownership bias" (higher confidence in the model's own answer than the same answer framed as user input); a reframing fix (Sections 3-5).
Models and benchmarks: Llama 3.1 (8B, 70B), Qwen3 (4B, 30B), Gemma 3 (4B, 27B), each base and instruct; MMLU main, GSM8K, TruthfulQA, open-ended MMLU; GPT-5.2 extension (Sections 3.1, 5.3). No code.
Findings: "instruction tuning boosts accuracy by 3.7% but degrades calibration, increasing ECE by 13.1% and Brier score by 6.5%"; chat template "adds another 2.74% to ECE"; total ECE increase 15.8% (Section 3.2).
Leaves open: no code, no execution labels, no hidden-state probe, no reasoning-on condition. Whether the base-to-instruct gap exists for code readouts, including verbal ones, is untested here. General-NLP precedent for the L2 base versus instruct component.
