# Selective Generation for Code (2505.13553)
Status: preprint only (first posting May 2025 per arXiv id; v4 29 Oct 2026; "ICML" appears only as a template keyword). Source: research/notes/towards-functional-correctness-of-code-models-with-selective-generation.md (12.2k words). Text basis: FULL TEXT.
Measured: a selective code generator that abstains by thresholding a score, with a calibrated bound on the false discovery rate of code entailment (FDR-CE), using fuzz-generated unit tests as labels (Sections 4, 4.7).
Models and benchmarks: GPT-4o, Gemini 1.5 Pro, GPT-4.1, CodeLlama 13B-instruct, DeepSeek-R1 (Section 5.1); APPS-f, Mercury-f, HumanEval-f, MBPP-f, Python only.
Findings: GPT-4o on APPS-f (eps_S = 0.3): SCG FDR-CE 0.224 +/- 0.018 at efficiency 0.337 +/- 0.011; no abstention 0.431 +/- 0.011 (Table 1). The guarantee needs i.i.d. data (Limitations).
Leaves open: scores are sequence likelihood variants (default length-normalized); no verbal confidence, probe, or sampling readout; abstention with a guarantee, not budget routing against random and oracle allocation; no confidence-update measurement.
