# LLMs Encode Their Failures, pre-generation probes and routing (2602.09924)
Status: preprint only (arXiv 2602.09924v4, 11 Aug 2026). Source: research/notes/llms-encode-their-failures-predicting-success-from-pre-generation-activations.md. Text basis: FULL TEXT.
Measured: linear and MLP probes on pre-generation activations predicting success under greedy, Maj@K, and Pass@5 decoding; probe-guided routing across a model pool (Sec 3 to 5).
Models and benchmarks: GPT-OSS-20B (low, medium, high), DeepSeek-R1-Distill-Qwen-7B, Qwen2.5-Math, Qwen2.5-Coder 3B and 7B, Qwen2.5-1.5B; MATH, GSM8K, AIME, E2H-AMC, LiveCodeBench (Sec 4.1, Table 2).
Findings: "routing queries across a pool of models can match the performance of the best-performing model whilst reducing inference cost by up to 70% on MATH" (Abstract); GPT-OSS-20B probe AUROC falls "from 0.78 to 0.64" as reasoning rises from low to high (Sec 4); LiveCodeBench appears only in Table 2 probe AUROCs (Pass@5 targets).
Leaves open: routing results are math, not code; code evidence is one probe-versus-surface-feature table; no verbal, token-probability, or sampling readout; no transfer to code (Limitations). So no L3 code routing against oracle and random (L3 questions 1, 5).
