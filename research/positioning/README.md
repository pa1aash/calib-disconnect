# research/positioning

Outputs of the literature-positioning run: fetched source notes, per-candidate occupancy verdicts,
the ranked contribution recommendation, the verified BibTeX file, and a digest. Every finding is
tracked here. Records copied from the literature-search tool's working directories are synced
into this folder so that nothing the verdicts rely on exists only in an untracked location.

Scope and output contract: `docs/s3/POSITIONING_BRIEF.md`.
