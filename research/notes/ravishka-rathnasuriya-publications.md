summary: 'Publications page for Ravishka Rathnasuriya, PhD student at UT Dallas advised
  by Wei Yang (fetched 2026-07-17). CONFIRMS the UT Dallas group''s active research
  line in code-model uncertainty/reliability: published work includes ''When to Answer
  and When to Defer: A Decision Framework for Reliable Code Predictions'' (ICSE-NIER
  2026) and ''On-the-Fly Input Adaptation for Reliable Code Intelligence'' (ICSE-NIER
  2026), plus adjacent work on input adaptation for deep code models (CodeImprove,
  ICSE 2025) and dynamic-DL-system robustness (USENIX Security 2025). MOST IMPORTANT
  FINDING: the ''Submitted, Under Review'' section lists two not-yet-public papers
  by the same authors with titles directly on-topic for the proposed AAAI-27 headline:
  (1) ''Beyond Confidence: Rethinking Uncertainty Calibration in Deep Code Models''
  and (2) ''Beyond Execution: Uncertainty Estimation and Abstention in LLM-Based Code
  Generation'' (both Rathnasuriya* & Wei Yang). Neither could be located on arXiv
  or elsewhere as of this fetch — their exact contribution, mechanism, and whether
  they use per-test-case dense confidence structure are unknown — but the titles alone
  establish this group is actively and specifically working the code-confidence-calibration
  space, and ''Beyond Execution'' in particular directly engages execution-based uncertainty/abstention.
  Also listed: an ongoing project ''Selecting Effective Code Generations via Black
  Box Approach on Code LLMs,'' which could plausibly involve per-test or per-sample
  confidence signals but has no further detail available.'
