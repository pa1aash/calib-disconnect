## Headline findings: method inventory (`docs/s2/METHOD_INVENTORY.md`)

Across 30 element-by-version rows: 11 AGREE, 15 DIFFER, 4 ABSENT. These record divergences and do
not say which side is right.

1. Correctness label: v1 text says the deterministic tau = 0.1 generation; code labels the first
   tau = 0.8 sample (`src/v1_baseline/exp1_optimized.py:134`).
2. Log-probability confidence: v2 and v3 texts give sigmoid(mean log p); the producing code computes
   exp(mean log p) (`src/v2_comprehensive/exp_v2_comprehensive.py:191`,
   `src/v3_multimodel/exp_v3_all.py:208`).
3. Confidence and label often come from different generations (fresh sample for log-prob, separate
   response for verbal, first or 11th sample for the label), which the texts do not state.
4. AST confidence: text describes the largest-cluster share; code uses
   max(0, 1 - (K - 1)/9) over distinct AST dumps (`exp_v3_all.py:267`).
5. Verbal prompts in the texts are not the prompts in the code; unparsed verbal answers default
   silently to 0.6.
6. TACE: code uses floor(sqrt n) equal-count bins with a 0.01 gap filter and share weighting
   (`exp_v3_all.py:80`), unlike the text.
7. The v2 "held-out" SFT set overlaps the SFT training source; v1 text gives an SFT tier threshold
   of 0.8, code uses 0.7.
8. Stored Brier and AUROC in v2 and v3 are bootstrap means, not point estimates.
9. Generation is unseeded in v1 to v3; only bootstrap and data splits use seed 42.

## Venue facts (`docs/s2/venue/TMLR_RUBRIC.md`)

- No page limit; length must be justified, and main bodies over 12 pages get longer review times.
- Double-blind: the PDF, supplementary material, and linked artifacts must be anonymized; arXiv
  preprints are allowed.
- A broader impact statement is required only for work with significant risk of harm. Use of LLM
  tools must be disclosed in a first-page footnote (TMLR FAQ).
- The official style file is mandatory and must not be altered. The template
  (JmlrOrg/tmlr-style-file at `7bf90ef`) builds locally with latexmk to 7 pages.
- Certifications (awarded after acceptance): Outstanding, Featured, Reproducibility, Survey, J2C,
  and Expert. TMLR stopped considering survey papers on 2026-09-01.
