## 2. Load-bearing quotes

Thinking toggle on identical weights:
- Qwen/Qwen3-8B card (same text in Qwen3-14B): "**Uniquely support of seamless switching between thinking mode** (for complex logical reasoning, math, and coding) and **non-thinking mode** (for efficient, general-purpose dialogue) **within single model**"; code comment "enable_thinking=True # Switches between thinking and non-thinking modes. Default is True."; "### `enable_thinking=False` ... In this mode, the model will not generate any think content and will not include a `<think>...</think>` block." Sampling advice differs by mode: thinking "`Temperature=0.6`, `TopP=0.95`, `TopK=20`, and `MinP=0` ... **DO NOT use greedy decoding**"; non-thinking "`Temperature=0.7`, `TopP=0.8`, `TopK=20`, and `MinP=0`". Mechanism: Qwen3 TR (arXiv 2505.09388) Sec. 4.3 "Thinking Mode Fusion": "The goal of the Thinking Mode Fusion stage is to integrate the 'non-thinking' capabilities into the previously developed 'thinking' model."
- Qwen/Qwen3.5-9B card (Qwen3.5-27B and Qwen3.6-27B similar): "Qwen3.5 models operate in thinking mode by default ... These are vision-language checkpoints ("Type: Causal Language Model with Vision Encoder"; architecture `Qwen3_5ForConditionalGeneration`).
- openai/gpt-oss-20b card: "**Configurable reasoning effort:** Easily adjust the reasoning effort (low, medium, high)". No "off" setting is stated; this is a graded effort control, not an on/off toggle. TR (arXiv 2508.10925) Sec. 2.5.2 "Variable Effort Reasoning Training".
