# paper

The TMLR manuscript, written fresh. No legacy manuscript under `papers/` is its base.

- `tmlr-template/`: official TMLR style files, unmodified (`tmlr-template/PROVENANCE.md`).
- `figures/`: figure sources and renders.
- `STYLE.md`: the binding writing brief for every drafting pass.

Numbers enter the text only through generated macros traced to `analysis/`.
